# Threat Calculator

Вебдодаток/PWA для оцінки ймовірних загроз.

## Можливості
- контрольна точка на карті;
- додавання кількох цілей;
- відстань до контрольної точки;
- ETA за заданою швидкістю;
- 450 км/год як значення за замовчуванням;
- позначення, чи швидкість введена вручну, чи підставлена;
- кількість цілей;
- статистична ймовірність перехоплення;
- очікуваний залишок;
- швидкі розрахунки для 10 / 50 / 100;
- збереження контрольної точки в браузері;
- адаптація для телефону/планшета;
- PWA.

## GitHub Pages
У Settings → Pages оберіть Deploy from a branch, branch main, folder /root.

> Результати є статистичною оцінкою, а не точним прогнозом маршруту чи фактичного перехоплення.
